# Video Production Blueprint (Remotion-Optimized Animation Column)

Only the `animation` rows were rewritten. All `twitter` and `website` rows are unchanged.

**Global Remotion rules (apply to every animation component):**
- Canvas 1920x1080 @ 30fps (60fps only for the gear loop and the kinetic text cards). Background `#070B19`.
- Palette: Cyan `#00F0FF`, Coral `#FF3366`, Amber `#FFB800`, Surface `#111A33`, Green `#2BE38B`, White `#EAF0FF`.
- Build everything from inline SVG, CSS and Lucide icons. No 3D engine. Use generic icons by default. Use a real brand logo only where a scene names that company and the logo adds recognition; those slots are written as `<Logo name="..."/>` and are listed in the **Logo & Asset Checklist** below. `<Logo/>` loads `public/logos/<name>.png` with `staticFile()`.
- Entrances: `spring({ fps, frame, config: { damping: 14, stiffness: 90 } })`. Staggers: `delay = index * 6` frames.
- Wrap each scene in `<Sequence>`, and write each component as `<Scene durationInFrames={...}>` so the editor can trim it to the voiceover.
- Fonts: Inter (UI), JetBrains Mono (terminal text), loaded with `@remotion/google-fonts`.
- **Visual style: clean motion graphics.** Dark navy canvas with one soft radial glow. Typography-led, one idea per scene, max 3 colors per scene, generous whitespace. Geometry only (circles, rounded rects, lines, arcs, grids) plus Lucide icons; no illustrated people, robots, cities or characters. Strokes are 2-3px with round caps, fills are flat, and glow is used only on the active element.
- **Motion:** one element animates at a time, in sync with the narration. Entrances use `spring`, lines draw on with `strokeDashoffset`, numbers count up, and camera moves are a slow scale/translate on a wrapper. Favor what Remotion does best: UI, terminal and code mockups, diagrams, charts and kinetic text.

### Remotion Implementation Cheatsheet

1. **Project setup:** `npx create-video@latest`, add `@remotion/google-fonts`, `lucide-react`, `@remotion/shapes`, `@remotion/noise`. One file per component in `src/scenes/`, one `Root.tsx` registering every `<Composition>` at 1920x1080, 30fps.
2. **Reusable helpers (build first):** `useSpring(delay)`, `<Typewriter text speed/>`, `<GlowRing/>`, `<Card/>`, `<Cursor path/>`, and a `colors.ts` with the palette above.
3. **Timing:** Render each scene to its own MP4 (`npx remotion render <id> out/<id>.mp4`), then place them in your editor against the voiceover. The durations above are targets; adjust `durationInFrames` after you record the narration.
4. **Screen capture standards (twitter and website rows):** Screen Studio or OBS at 4K 60fps, system dark mode, crop out the browser chrome, and add a blurred backdrop or slight perspective tilt.
5. **Logos:** Build one shared `<Logo name="openai" size={96}/>` component that wraps `<Img src={staticFile(`logos/${name}.png`)}/>` with `objectFit: "contain"`. Keep Lucide icons for generic concepts (lock, terminal, bell, browser). Placeholder PNGs ship in `assets.zip` so every scene renders before you replace them with the real files.
