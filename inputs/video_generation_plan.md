## 2. Remote RunPod Video Generation Instructions

To generate the animated clips via the RunPod GPU pipeline:

### Step 1: Sync Generated Images to RunPod
```bash
rsync -avz -e "ssh -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null -i $HOME/.ssh/id_ed25519_runpod -p 11489" \
  image_output/*.png root@66.92.198.226:/workspace/youtube-video/inputs/
```

### Step 2: Batch Execution Command Template
Run inference on RunPod for each image using `scripts/generate_remote_video.sh generate`:

```bash
# Example for Image 1 (Cold Open):
bash scripts/generate_remote_video.sh generate image_1.png \
  "2D vector animation, camera slowly dollies forward toward server rack, red beacon pulses with glowing neon strobe, electric cyan circuit traces pulse across floor, no camera shake, solid midnight navy background" \
  scene_01_sandbox_escape

# Example for Image 29 (Action Pending Approval):
bash scripts/generate_remote_video.sh generate image_29.png \
  "2D vector animation, camera slowly pushes into approval modal, green APPROVE button pulses with bright glow, dual digital keys rotate 45 degrees unlocking concentric vault rings, clean flat vector motion, seamless navy background" \
  scene_29_approval_vault
```

### Step 3: Pull Finished 1080p Video Clips
```bash
bash scripts/generate_remote_video.sh pull-videos
```
Finished video clips will be saved in `video_output/*_1080p.mp4`.
